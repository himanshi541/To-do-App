Basic Setup
1.Create and Open directory in Terminal
2. >>rails new .
3.Create migration >> rails generate migration <migration_name> <attribute>: <datatype>
4.>>rails db:migrate
5.>>rails s
5.Open schema.rb and add attribute if haven't added during step 3
6.Open route.rb and add route name >> resources: route_name to see the path on rails/info/path_name at localhost:3000
