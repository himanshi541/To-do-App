# README

This README contains two CRUD apps (with and without scaffold)
Tasks - CRUD app with Scaffold 
To-do List - CRUD app wihout Scaffold

Basic Setup
-Create and Open directory in Terminal
- >> rails new .
- >> Create migration >> rails generate migration <migration_name> <attribute>: <datatype>
- >> rails db:migrate
- >> rails s
- Open schema.rb and add attribute if haven't added during step 3
- Open route.rb and add route name >> resources: route_name to see the path on rails/info/path_name at localhost:3000

 Features

- Create, View, Update, and Delete Tasks
- Create, View, Update, and Delete To-Do Lists
- Form validations
